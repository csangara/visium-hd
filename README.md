# Deconvolution of VisiumHD

This repository contains scripts for the analysis done in Chapter 4 (and a bit of Chapter 5) of my dissertation.

* Each directory beginning with a `visium_hd*/` contains analysis scripts of a certain tissue.
* The `UMI_downsampling*/` directories analyzes the effect of decreasing UMIs on deconvolution results (Figure 4.3)
* `visiumify_55um` compares an artifically binned VisiumHD data to old Visium (Supplementary Figure 4.5)

Within those directories are separate READMEs that explain the scripts, as well as what figure(s) is generated by the script.

## Environments

### Python

Three conda environments are used for the analysis: `spatialdata`, `napari-sparrow`, and `stardist`. They are all very similar but the latter two contains the installation of SPArrOW and StarDist, respectively. Check the `import` functions at the beginning of the notebooks to see if SPArrOW or StarDist is necessary, otherwise the `spatialdata` environment is likely the one being used. 

* The [SpatialData](https://spatialdata.scverse.org/en/latest/installation.html) environment is the default being used for data exploration and analysis.
* The [SPArrOW](https://github.com/saeyslab/napari-sparrow) environment is usually needed for the custom binning and gene scoring functions.
* The [StarDist](https://github.com/stardist/stardist) environment is used for nuclei segmentation.

Exported yaml files are provided in the `env/` directory for each environment. These are only meant to inform you of the packages (and versions) used in each environment. To create each environment, it is best to instead follow the installation linked to in the above bullet points.

### R

These are the main packages that are most often used in the analyses:
* Seurat (5.1.0)
* tidyverse (2.0.0)
* spdep (1.3.5)
* sf (1.0.16)
* Matrix (1.6.5)

The Matrix package is installed when you install Seurat, but I provide the version number here because sometimes there can be version and behavior conflicts between versions.

### File conversion

File conversion between Seurat and AnnData is always a bit tricky. I used a mix of [`schard`](https://github.com/cellgeni/schard) (version 0.0.1) and [`sceasy`](https://github.com/cellgeni/sceasy) (version 0.0.7) but they're always a bit annoying to do. Feel free to use alternatives like [anndataR](https://github.com/scverse/anndataR), [SeuratDisk](https://github.com/mojaveazure/seurat-disk), etc. as you see fit.

### HPC usage

Many `.pbs` files are also provided in this repo that can be submitted via the UGent HPC simply by using `qsub filename.pbs`. I usually just submit it via the default cluster (doduo). I also created an conda environment on the HPC that has SpatialData and SPArrOW installed in order to run some steps of the analysis.
